# Mercado Cafe Bar

Sassy modern marketing site for Mercado Cafe Bar, West Didsbury.

## Develop

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Stack

Next.js · Tailwind CSS · Framer Motion

Content sourced from Instagram (@mercado.mcr) and Uber Eats menu.
